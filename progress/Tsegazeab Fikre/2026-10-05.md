## ✅ What I Did Today

- Created `src/engine/output_scanner.py`, the first part of the **output scanner** for the firewall project.
- Worked on the outbound side of the firewall: while the existing firewall checks what users send **to** the AI, this scanner checks what the AI sends **back**, so private data does not leak out.
- Implemented the core data structures and helper functions for the scanner:
  - **`Span`** — marks a piece of text, for example "characters 10 to 19 are a secret".
  - **`merge_spans`** — cleans the marked pieces by fixing ranges that go outside the text, removing empty ones, and joining overlapping or touching spans.
  - **`redact_spans`** — replaces each marked piece with a safe label such as `[REDACTED:PII]`. The label never contains the original text.
  - **`redact_completion_payload`** — applies the same redaction to a full AI reply. It works on a copy, so the original reply is never changed.
  - **`OutputScanResult`** — holds the scan decision (PASS, BLOCK, REDACT, or WARN).
  - **Two empty stubs** — `detect_system_prompt_leak` (to be filled in on Wednesday) and `detect_pii` (to be filled in by P2 on Friday). They return an empty list for now so other team members' code can already import them.
- Tested the implementation thoroughly and followed the team workflow for branching, committing, and pushing.

## 📚 What I Learned

- **Output Scanning / Data Leak Prevention:** Learned how a firewall needs to inspect not only incoming user input but also outgoing AI responses to prevent sensitive data from leaking.
- **Span-Based Redaction:** Learned how to represent sensitive regions of text as spans and how to safely merge and clean them before redaction.
- **Defensive Programming:** Reinforced the importance of not mutating original data — redaction works on a copy so the original AI reply is preserved.
- **Team Interface Design:** Learned how to design stubs with stable signatures so teammates can import and build on them before the full logic is implemented.
- **Collaboration Workflow:** Practiced a clean Git workflow — feature branch, single-file change, GitHub push, and a PR into `main` awaiting one review.
