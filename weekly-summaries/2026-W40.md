**What I did today:**

**What I learned:**

- **Registers and memory:** The CPU hierarchy runs from registers to cache to RAM. Key 64-bit registers are RAX (calculations and return values), RSP (stack pointer to the current top of the stack), and RIP (instruction pointer). Function arguments are passed in RCX, RDX, R8, and R9, with extra arguments going on the stack.
- **Core instructions:** `mov` copies data without destroying the source. `add` and `sub` store the result in the destination. `push` and `pop` add to and remove from the top of the stack. `call` saves the return address and jumps to a function, and `ret` returns to that saved address, with the return value usually in RAX/EAX. `nop` does nothing and is used to replace instructions while keeping the size the same.
- **LEA vs MOV:** `lea` calculates an address and stores it without reading memory, while `mov rax, [rcx+8]` calculates the address and then reads the memory at that location.
- **Security concepts:** ASLR randomizes a program's memory locations. DEP enforces read/write/execute permissions, so data is read-write and code is read-execute.
- **Base address and offset:** The base address is the starting address of something (a stack, array, or buffer), and offset = address − base address.
- **Control flow and flags:** Unconditional jumps use `jmp`. Conditional jumps depend on flags set by `cmp` (which subtracts without storing the result). ZF is set when the result is zero, SF when it's negative, CF for unsigned borrow, and OF when a signed result doesn't fit. Signed jumps (`jl`, `jg`, `jle`, `jge`) are distinct from unsigned ones (`jb`, `ja`, `jbe`).
